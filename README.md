# Tab Switcher & Search Chrome Extension

A powerful, keyboard-centric Chrome extension that combines efficient tab switching with a universal search capability (Tabs + Bookmarks + History).

![Icon](icon128.png)

## Features

- **Quick Tab Switching**: Press `Option + TAB` (customizable) to view and switch between open tabs with a visual preview.
- **Universal Search**: Press `Command + Shift + K` (customizable) to open the all-in-one search panel.
  - Search open **Tabs**
  - Search **Bookmarks**
  - Search Browsing **History**
  - Search **Web** (Google/Custom Engine) directly if no local results match
- **Keyboard Navigation**: Fully navigable via arrow keys and Enter.
- **Customizable Shortcuts**: Easily record and save your preferred keyboard shortcuts in the options page.
- **Privacy First**: All searching happens locally on your device. No data is sent to external servers (except when you explicitly choose to search the web).

## Installation (Developer Mode)

1.  Clone or download this repository.
2.  Open Chrome/Edge and navigate to `chrome://extensions` or `edge://extensions`.
3.  Enable **Developer mode** (toggle in the top right corner).
4.  Click **Load unpacked** button.
5.  Select the `tab-switcher-extension` directory from this repository.

## Usage

- **Switch Tabs**: `Option + Tab` (Default) -> Use Arrow keys to select -> Release keys or Press Enter.
- **Search**: `Command + Shift + K` (Default) -> Type query -> Select result -> Enter.
